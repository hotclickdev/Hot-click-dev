# Instrucción: reportes de SonarCloud

Obligatoria para los agentes. Proyecto `hotclickdev_Hot-click-dev`. Verde: quality gate **Passed** y las letras de seguridad, hotspots, confiabilidad y mantenibilidad en **A**. Un cambio que rompa eso no se entrega.

Si un punto no se entiende, se lee el archivo de ese cuadro. Si aún no queda claro, se consulta la documentación de SonarCloud (https://docs.sonarsource.com/sonarqube-cloud/) o la regla en https://rules.sonarsource.com/. No se inventa una excepción.
